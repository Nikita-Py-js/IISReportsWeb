# Changelog

## 3.0.2 — 2026-10-11

### Самостоятельная установка
- Полностью переработана документация: новый сервер с IIS, без старой версии и прежнего ConnStr.
- Добавлены Install-Prerequisites, New-InstallConfig, Install-Web, Initialize-Database, Grant-DatabaseAccess, Register-LogSource.
- SQL можно настроить без установленного SSMS/sqlcmd через System.Data.SqlClient.
- Новый сайт/пул создаются явно; публикуется только web/, с Default Document и Windows Authentication.
- Никаких фиктивных источников W3SVC1–3 на чистой базе.
- Разделены локальные Windows-логины и удалённые SQL-логины.
- Конфигурации создаются в закрытой папке; существующие файлы не перезаписываются.

### Исправления и консолидация
- Включены исправленный SQL-установщик, DEFAULT-литералы, явные datetime2-параметры.
- Включён изолированный Test-Http: между запросами не переносятся заголовки.
- PublicOrigin настраивается отдельно от внутренней IIS-привязки.
- Origin-backup больше не сохраняется рядом с публичным Web.config.
- Enable-WindowsAuth проверяет существование сайта и фактический физический путь.
- Runtime и EXE помечены 3.0.2; схема остаётся 300.
- Упаковка Windows ZIP ограничена манифестом и проверяет соответствие исходников сборке.

### Документация
- README с навигацией, чистая установка, SQL, конфигурация, безопасность, эксплуатация, обновление и troubleshooting.
- Добавлены пример Windows CI, issue templates и карта исходников EXE.
- Убраны инструкции, привязанные к именам/каталогам конкретного прежнего сервера.

### Границы
- Не меняется базовая архитектура IIS + ASP.NET Framework + MSSQL + Windows-служба.
- Нет удаления истории или автоматического перехода на другую СУБД.
- Не заявляется новая функциональность HTTPERR/FREB, OpenTelemetry, IPv6-обогащения или multi-agent.

## Предыдущая консолидированная v3

Windows-аутентификация, строгий CSRF, отдельная схема ir3, служба, контрольные точки, HTTP-проверки, инциденты и outbox. Пользователь подтвердил исправление публичного Origin; полноценная автоматическая приёмка новой установки всё равно выполняется на каждом сервере.
