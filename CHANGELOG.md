# Изменения

## 3.1.1 — 2026-10-12

### Установка и документация
- Единый `Install.ps1` и постоянные `.psd1`-параметры вместо зависимости от переменных PowerShell.
- Проверки имён, локальных путей, непересекающихся каталогов, SQL-параметров и трёх режимов привязки.
- Обязательный этап создания закрытой папки и обоих конфигурационных файлов; отдельный `Test-InstallConfig.ps1`.
- Безопасный повторный Config: сравнение существующих критических параметров, завершение неполной пары без перезаписи.
- XML создаётся через временный файл и атомарное перемещение, не через прямую запись конечного файла.
- Установщики проверяют успешную сборку и хеши EXE до публикации.
- Убраны рабочие вызовы icacls из установочных скриптов. Системные команды запускаются по абсолютным путям с собственным рабочим каталогом.
- Служба изначально Manual/Stopped; delayed-auto задаётся только после проверок на Start.
- Полностью переписана основная инструкция чистой установки. Добавлены таблица параметров и сценарий сохранения текущей установки.

### SQL и CSRF
- Сохранены SQLCONN-FIX1, BUILD-FIX1, SETUP-FIX1 и VERIFY-FIX1.
- Проверка DEFAULT теперь прекращает этап при ошибке.
- `csrf-check` проверяет корректный POST без обращения к SQL и без задания импорта.
- HTTP-тест использует csrf-check для отрицательных и положительного контроля; запрос с изменением состояния только при явном `-QueueScan`.
- Схема остаётся **310**, новой миграции в 3.1.1 нет.

### Не добавлено
SQL Server/Framework не входят в комплект. Нет подготовленного EXE, гарантий безошибочной работы или утверждения о пройденной Windows/SQL/IIS-приёмке в этой среде.

## 3.1.0 и исправления

Автоматическое обнаружение локальных сайтов, чекбоксы импорта, таблица DiscoveryState и схема 310. Последующие исправления: запуск сборки, строки подключения SQL, защищённые каталоги и проверка 19 таблиц.

## 3.0.x

Исходная MSSQL-схема ir3, Windows-агент, анализ ошибок/нагрузки, проверки URL, инциденты и CSRF.
