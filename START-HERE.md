# Начало работы

1. Распакуйте **весь проект** в `C:\Deploy\IISReports-3.1.1`, не в `wwwroot`.
2. Для новой установки откройте [docs/INSTALL.md](docs/INSTALL.md). Там есть все шаги, включая создание папки конфигураций.
3. Для установленной версии откройте [docs/UPGRADING.md](docs/UPGRADING.md). Не создавайте повторно существующий сайт.
4. Параметры хранятся в отдельном `.psd1`: не нужно восстанавливать `$pkg`, `$dbArgs` и другие переменные после открытия нового PowerShell.
5. После ошибки остановитесь. Не запускайте следующий шаг и не удаляйте конфиги/таблицы, чтобы обойти проверку.

**EXE не включён:** сборка на Windows создаёт `build\IISReports.Agent.exe`. Полные исходники входят в проект.
