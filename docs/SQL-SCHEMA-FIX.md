# Схема SQL и включённые исправления

[← README](../README.md) · [DATABASE](DATABASE.md)

Текущий `001-v3-schema.sql` — полный установщик схемы, не патч. В нём:
- schema/table/index/view создаются в правильном порядке;
- DDL выполняется отдельными дочерними пакетами;
- установка ограничена транзакцией с откатом при первой ошибке;
- проверяется присутствие ожидаемых столбцов перед индексами;
- правильно экранированы литералы DEFAULT `new`, `queued`, `open`, `pending`;
- роли runtime отделены от прав установки;
- **нет автоматической регистрации W3SVC1–3 для нового сервера**;
- существующие источники и dbo-история не удаляются.

Ошибка «ir3 не существует» может быть вызвана невыбранной БД, правами DBA, неудачей ранней команды или несовпадающей структурой. Сама по себе она не доказывает конкретную причину. Сохраняйте первую ошибку, а не только каскад последующих.

Повторная установка корректной схемы допустима. Если существующие таблицы имеют несовместимую структуру, установщик останавливается, а не стирает их.

`003-v3-verify.sql` проверяет объекты. `004-v3-defaults-audit.sql` только показывает определения DEFAULT и фактические состояния заданий; он не исправляет существующие строки. Для повреждённой ранней тестовой схемы сначала сделайте backup и отдельный план ремонта.

Приложение 3.0.2 продолжает ожидать schema version 300. Установочная версия SQL-файла и schema-version приложения — не одно и то же.
