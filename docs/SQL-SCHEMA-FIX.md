# Порядок подготовки SQL-схемы

[← README](../README.md) · [Чистая установка](INSTALL.md) · [Устранение ошибок](TROUBLESHOOTING.md)

> Это историческое описание исправления. В версии 3.1.1 оно уже включено. Не накладывайте старые ZIP-патчи поверх этого выпуска.

001-v3-schema.sql выполняет зависимые DDL-команды в отдельном динамическом контексте и прерывается при ошибке. После него применяется 005-auto-sources.sql. Для уже установленной схемы 310 доступна проверка -VerifyOnly без миграции.

Наличие сообщений об отсутствующих схемах, колонках и внешних ключах требует проверки первой ошибки SQL, выбранной базы и прав установочного аккаунта. По каскадному списку ошибок нельзя однозначно заключить, что причина всегда одна и та же.

Для установки используйте единый `Install.ps1` и файл `.psd1`, а не команды из предыдущих сообщений. Для работающего сайта используйте [UPGRADING.md](UPGRADING.md). Проверка на целевом Windows/IIS/SQL обязательна; статический анализ не заменяет выполнение.
