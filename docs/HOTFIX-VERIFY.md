# История исправления проверки схемы

[← README](../README.md) · [Чистая установка](INSTALL.md) · [Устранение ошибок](TROUBLESHOOTING.md)

> Это историческое описание исправления. В версии 3.1.1 оно уже включено. Не накладывайте старые ZIP-патчи поверх этого выпуска.

Схема 310 содержит 18 основных таблиц и DiscoveryState. 003-v3-verify.sql проверяет обязательные таблицы по именам, а 006-auto-sources-verify.sql — дополнительные объекты и версию 310. Дополнительные пользовательские таблицы допустимы. Неверные DEFAULT в 004-v3-defaults-audit.sql теперь останавливают проверку.

Нельзя удалять DiscoveryState или другие таблицы, чтобы пройти проверку количества. Проверяющие SQL-файлы не меняют существующие данные.

Для установки используйте единый `Install.ps1` и файл `.psd1`, а не команды из предыдущих сообщений. Для работающего сайта используйте [UPGRADING.md](UPGRADING.md). Проверка на целевом Windows/IIS/SQL обязательна; статический анализ не заменяет выполнение.
