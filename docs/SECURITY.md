# Безопасность: Windows Authentication, SQL, HTTPS и CSRF

[← README](../README.md)

## Три разных аккаунта

1. Windows-пользователь браузера: проверяется в `whoami`, получает роли Readers/Editors.
2. Пул IIS: читает Web.config и обращается к SQL от своего имени при Integrated Security.
3. Служба: читает журналы и работает с MSSQL как `NT SERVICE\IISReportsAgentV3`.

Вход Windows-администратором не отменяет правила приложения. Не используйте impersonation для передачи административного контекста браузера в SQL.

Windows Authentication должна быть включена, Anonymous — выключена. Установка не разблокирует глобально секции IIS и не отключает loopback/Kerberos-защиту Windows.

## PublicOrigin

`IISReportsPublicOrigin` — точные протокол, хост и порт **адреса браузера**. Не внутренний адрес прокси и не ID сайта.

```text
https://reports.example.test:8443
```

`http://localhost:801`, `https://reports.example.test:8443` и то же имя без нестандартного порта — разные Origin.

Проверка в браузере:

```javascript
location.origin
```

Изменить установленный конфиг с резервной копией:

```powershell
.\tools\Set-IISReportsPublicOrigin.ps1 `
    -WebConfig 'C:\inetpub\wwwroot\IISReportsV3\Web.config' `
    -PublicUrl 'https://reports.example.test:8443/'
```

Подставьте реальный адрес; затем синхронизируйте подготовленный конфиг и `.psd1`. Перезагрузите страницу для новой cookie/token-пары. Произвольные Forwarded/X-Forwarded заголовки не используются как доверенная настройка Origin.

## CSRF

Изменяющие действия требуют прав Editor, POST, допустимый Origin/Referer, заголовок `X-IISReports-CSRF`, cookie и защищённый MachineKey токен. Токен связан с пользователем, cookie, приложением, Origin и сроком.

- `GET action=csrf` выдаёт токен после проверки доступа.
- `POST action=csrf-check` проверяет весь механизм и возвращает `{ok:true, validated:true, mutation:false}`. Он не обращается к SQL и не добавляет задания.
- `Test-Http.ps1` создаёт отдельный HttpWebRequest на каждый запрос; переносит только cookie, не старые заголовки.
- Отрицательные CSRF-тесты ожидают конкретные 403-коды. Положительный контроль должен дать 200.
- Настоящий `refresh` отправляется тестом только с явным `-QueueScan`.
- HTTP 405 на GET-изменение — правильный отказ, не ошибка выдачи токена.

CSRF-защита не отключается для localhost или администратора. Режим local остаётся отдельным режимом доступа для разработки, но чистая установка использует Windows.

## Прокси и сертификаты

При ReverseProxy используйте внешний HTTPS PublicUrl и внутренний HTTP BindingUrl. Сертификат с закрытым ключом находится на TLS-терминаторе. Прокси должен поддерживать используемую Windows-аутентификацию; проверьте весь путь на реальном адресе. Доступ к backend ограничивается firewall.

Не ставьте `$trustSqlCertificate=$true` для решения ошибки сертификата сайта: это настройка другого соединения. HTTP-тест не отключает проверку HTTPS-сертификата.

## Права и секреты

- ConfigDirectory закрыта для обычных пользователей.
- Web.config читается пулом, Administrators и SYSTEM, а не всеми аутентифицированными пользователями.
- Папка службы закрыта; служба имеет чтение EXE/конфига и запись только в собственные logs.
- Задача discovery исполняется как SYSTEM, потому что читает конфигурацию IIS и назначает ACL. Агенту запрещена запись в её скрипты/снимок.
- Мониторинг URL/webhook ограничен заранее заданными allowlist хостов/портов; редиректы и автоматическая Windows-аутентификация удалённой проверки не включаются.
- Не предоставляйте панели публичный анонимный доступ. Ограничьте административную сеть.
- Не публикуйте конфиги, CSRF, cookie, дампы SQL, реальные логи или private key.

Хеш пакета проверяет целостность, не удостоверяет автора. Все скрипты привилегированной установки требуют проверки происхождения.

## Остаточные ограничения

Это не формальный аудит безопасности. Автодетектор ботов эвристический; GeoIP зависит от базы. Настройка доверенного DNS/CA, шифрования SQL, прав домена и сетевых границ остаётся ответственностью оператора. Windows/SQL/NTLM/Kerberos-проверки обязательны после развёртывания.
