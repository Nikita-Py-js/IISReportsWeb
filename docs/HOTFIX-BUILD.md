# История исправления сборки

[← README](../README.md) · [Чистая установка](INSTALL.md) · [Устранение ошибок](TROUBLESHOOTING.md)

> Это историческое описание исправления. В версии 3.1.1 оно уже включено. Не накладывайте старые ZIP-патчи поверх этого выпуска.

Ранние скрипты пытались запускать UnitTests.exe, не проверив, что компилятор действительно создал его. Текущий Build-And-Test.ps1 использует отдельные процессы с явной рабочей папкой, файлы аргументов .rsp, журналы, проверку кода завершения, наличия и метаданных EXE/DLL. BUILDINFO.json появляется только после успешных локальных тестов.

Если EXE не создан, откройте build/LAST-BUILD-LOG.txt и указанный в нём журнал. Не создавайте пустой EXE и не копируйте старую сборку.

Для установки используйте единый `Install.ps1` и файл `.psd1`, а не команды из предыдущих сообщений. Для работающего сайта используйте [UPGRADING.md](UPGRADING.md). Проверка на целевом Windows/IIS/SQL обязательна; статический анализ не заменяет выполнение.
