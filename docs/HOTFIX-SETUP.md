# История исправления путей и ACL

[← README](../README.md) · [Чистая установка](INSTALL.md) · [Устранение ошибок](TROUBLESHOOTING.md)

> Это историческое описание исправления. В версии 3.1.1 оно уже включено. Не накладывайте старые ZIP-патчи поверх этого выпуска.

В текущем комплекте ограничение доступа к новым конфигурационным папкам выполняется через .NET Framework, а не запуском icacls.exe. Новые родительские папки создаются автоматически; существующие заполненные папки с неподходящими ACL не перезаписываются. Внешние команды запускаются с явным рабочим каталогом.

Шаг Config создаёт оба файла, затем проверяет их. Web и Agent отказываются продолжать без подготовленных конфигураций.

Для установки используйте единый `Install.ps1` и файл `.psd1`, а не команды из предыдущих сообщений. Для работающего сайта используйте [UPGRADING.md](UPGRADING.md). Проверка на целевом Windows/IIS/SQL обязательна; статический анализ не заменяет выполнение.
