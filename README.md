# IIS Reports 3.1.1

Анализ файловых журналов IIS: **IIS + ASP.NET .NET Framework + Microsoft SQL Server + Windows-служба**. Все исходники веб-приложения, агента, установщика и тестов входят в проект.

> Этот выпуск объединяет исправления SQLCONN, BUILD, SETUP и VERIFY. Для установки используется **один сохранённый файл параметров**, а не переменные из предыдущего окна PowerShell. Не требуется предыдущая версия IIS Reports.

## Что исправлено в 3.1.1

- Корневой `Install.ps1` выполняет явно выбранный шаг и каждый раз читает параметры из `.psd1`. После закрытия PowerShell не теряются пути, имя SQL, режим HTTPS или PublicOrigin.
- Шаг `Config` создаёт закрытую папку **и оба файла**, затем проверяет результат. `Web` и `Agent` проверяют необходимые файлы до установки.
- Совпадающие существующие конфиги можно проверить и использовать повторно. Несовпадающие не перезаписываются; неполная пара достраивается только после проверки имеющегося файла.
- Сборка проверяет каждый EXE/DLL, сохраняет журналы и не оставляет маркер успешной сборки после ошибки.
- Строки SQL используют корректные ключи `Data Source` / `Initial Catalog`. Реальная проверка соединения отделена от локального теста построителя.
- Проверка схемы учитывает 18 базовых таблиц и `DiscoveryState`; ошибочный DEFAULT теперь останавливает проверку.
- Рабочие операции NTFS выполняются через .NET; оставшиеся системные команды запускаются с абсолютным путём, явным рабочим каталогом и проверкой результата.
- Для тестирования CSRF добавлен `POST action=csrf-check`: корректный запрос проверяется **без добавления задания в очередь**.
- Служба создаётся в состоянии Manual/Stopped. Автоматический запуск настраивается на шаге `Start`, после SQL и проверки HTTP/CSRF.

Подробности: [CHANGELOG.md](CHANGELOG.md).

## Возможности

| Область | Реализация |
|---|---|
| Источники | Автообнаружение локальных сайтов IIS и их реальных каталогов; сохранённые чекбоксы мониторинга |
| Импорт | Дочитывание по байтовому смещению, контрольные точки MSSQL, сырые записи, карантин, контрольные суммы блоков |
| Аналитика | Клиенты, пользователи, URL, 404/5xx, подстатусы, Referer, CSV, времена ответа |
| Нагрузка | RPS/RPM, графики, персентили, сравнение периодов |
| Мониторинг | Проверки URL, редактор правил, инциденты, очередь JSON-webhook |
| Безопасность | Windows Authentication, роли, CSRF, фиксированный PublicOrigin |
| Обогащение | Локальные GeoIP/ASN CSV для IPv4; эвристическая классификация ботов |

**«Все журналы» — файловые W3C-журналы локальных сайтов IIS.** HTTPERR/FREB, ETW-only, gzip, централизованные и UNC-журналы не входят в автоматический импорт. IPv6 GeoIP и трассировки OpenTelemetry не добавлены.

## Источники в веб-интерфейсе

Новый сайт обнаруживается и включается автоматически. Во вкладке «Источники» снимите или установите флажки и нажмите **«Сохранить выбор»**.

Пауза не удаляет историю. При возобновлении агент дочитывает доступные файлы с контрольной точки. Настройки журналирования самого IIS и NTFS-права не переключаются этими флажками.

![Источники — демонстрация на подставном API](docs/images/sources.png)

Изображение получено в браузерном тесте, а не на рабочем сервере.

## Требования

Одного IIS недостаточно. Нужны Windows Server, Windows PowerShell 5.1 x64, .NET Framework 4.8/4.8.1, компоненты IIS ASP.NET/Windows Authentication и доступный SQL Server. SQL Server **не входит** в ZIP и не устанавливается автоматически.

Сборка выполняется включённым скриптом на Windows; Visual Studio, Node.js и Python для работы приложения не нужны. В исходном ZIP **нет предварительно собранного EXE**. Подробности: [требования](docs/PREREQUISITES.md).

## Быстрый ориентир

```powershell
# Windows PowerShell 5.1 x64 от администратора.
# Распакуйте комплект в C:\Deploy\IISReports-3.1.1.
Set-Location 'C:\Deploy\IISReports-3.1.1'
if (Test-Path 'C:\Deploy\IISReports.setup.psd1') {
    throw 'Файл параметров уже существует: проверьте его, не перезаписывайте.'
}
Copy-Item '.\setup\LocalHttp.psd1' 'C:\Deploy\IISReports.setup.psd1'
notepad 'C:\Deploy\IISReports.setup.psd1'
.\Install.ps1 -SettingsFile 'C:\Deploy\IISReports.setup.psd1' -Step Check
```

Это только начало, не полная установка. Заполните `Editor` и проверьте SQL. Для HTTPS выберите соответствующий шаблон. Остальные шаги приведены в [INSTALL.md](docs/INSTALL.md).

## Каталоги

```text
Install.ps1                    единая точка входа для чистой установки
setup/                         шаблоны параметров: LocalHttp, Https, ReverseProxy
web/                           только эта часть публикуется IIS
agent/                         исходники и проект службы
agent/source/                  автономный набор исходников EXE
discovery/                     защищённый издатель списка сайтов IIS
sql/                           создание/добавочные миграции/проверки схемы ir3
tools/                         установочные и диагностические скрипты
tests/                         локальные, SQL, HTTP, браузерные тесты
docs/                          документация Markdown
```

Веб-процесс не импортирует файлы вместо агента. Отдельная задача SYSTEM публикует защищённый снимок конфигурации IIS и выдаёт агенту чтение локальных журналов. Служба работает под `NT SERVICE\IISReportsAgentV3`, не под SYSTEM.

Одна база данных рассчитана на **один IIS-сервер / один агент**.

## Проверки и ограничения поставки

Не называйте прохождение статических тестов успешной установкой Windows. В этой среде проверены исходники/упаковка и браузер с подставным API. Windows PowerShell, реальный IIS/NTLM/Kerberos, SQL и служба здесь не запускались. Список и результаты: [TESTING.md](docs/TESTING.md).

Проект не опубликован в GitHub автоматически. Файлы Markdown и `.github` готовы для размещения в вашем репозитории. Прежде чем публиковать, проверьте отсутствие локальных конфигов, журналов и секретов.
