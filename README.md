# IIS Reports Simple 3.2.0

**IIS + ASP.NET Framework + SQL Server. Без Windows-службы, Планировщика и EXE.**

[Установка](docs/INSTALL.md) · [Переход с 3.1.x](docs/UPGRADE.md) · [Настройки](docs/CONFIGURATION.md) · [Удалённый SQL](docs/REMOTE-SQL.md) · [Проверки](docs/TESTING.md)

## Что изменилось

Панель сама выполняет небольшую порцию импорта по HTTP-запросу. Кнопка **«Обновить / импортировать»** и автообновление страницы используют один и тот же код. При открытии страницы тоже выполняется один проход.

Не нужны:
- `IISReportsAgentV3`, задача `IISReports-DiscoverSites`, снимок `sites.json` из ProgramData;
- сборка агента, `Install.ps1 -Step ...`, отдельная папка подготовленных конфигураций;
- `Editor`, обязательная Windows Authentication, `IISReportsPublicOrigin`, выдача CSRF-токенов и проверки безопасности, блокирующие запуск.

Остались SQL-параметры, экранирование HTML, транзакции импорта и защита контрольных точек: это защита данных, а не дополнительные этапы установки.

> **Предел упрощения:** пока браузер закрыт или вкладка неактивна, автоматический импорт не выполняется. После возвращения доступные журналы дочитываются. Уже начатый HTTP-запрос может закончить текущую порцию и после закрытия страницы. Если IIS успел удалить исходный файл до его импорта, восстановить неимпортированные строки не получится. Постоянного фонового мониторинга этот вариант не обещает.

## Быстрый старт на вашем локальном SQL Server

Распакуйте ZIP в `C:\Deploy`. Откройте **Windows PowerShell 5.1 x64 от администратора**.

Если уже установлена старая версия, сначала остановите её отдельные компоненты:

```powershell
& 'C:\Deploy\IISReports-Simple-3.2.0\Stop-Legacy.ps1'
```

Установка нового отдельного сайта:

```powershell
& 'C:\Deploy\IISReports-Simple-3.2.0\Setup.ps1' -SqlServer 'localhost' -Database 'IISReports' -TrustSqlCertificate
```

Откройте **http://localhost:8090/**.

`-TrustSqlCertificate` предназначен для вашего доверенного локального стенда с недоверенным SQL-сертификатом. Подключение шифруется, но подлинность сертификата не проверяется. При корректной доверенной цепочке уберите переключатель.

Setup создаёт/готовит базу, копирует сайт, записывает рабочий `Web.config`, выдаёт пулу права и настраивает локальную HTTP-привязку. На SQL нужны административные права текущего Windows-аккаунта. SQL Server не устанавливается автоматически.

## Что доступно

Обзор, клиенты и пользователи, HTTP-статусы и подстатусы, 404/5xx, Referer, детальные запросы, CSV, RPS и задержки, сравнение периодов, эвристики ботов, прежнее локальное GeoIP/ASN, контрольные точки.

**Источники:** каталоги `W3SVC<id>` под настроенными корнями журналов обнаруживаются автоматически во время импорта. Новые источники включены; флажки и кнопка «Сохранить выбор» сохраняют выбор в SQL. Снятие флажка не удаляет историю; повторное включение дочитывает накопившиеся файлы. Список каталогов может включать архивы уже удалённых IIS-сайтов.

**Алерты:** сохранён редактор правил и инциденты. По умолчанию правила оцениваются после импорта, не непрерывно. Активные HTTP-проверки и отправка webhook выполняются **только вручную** кнопкой «Выполнить проверку / отправку»: одна просроченная проверка и одна готовая отправка за проход. Исходящие адреса задаются в `Web.config`. Старые задания агента не исполняются автоматически.

## Упрощённый доступ

Приложение не требует логина само: доступ делегирован IIS/прокси/сети. Кто может открыть этот сайт, тот может читать отчёты и менять выбор источников. Новая установка слушает **127.0.0.1:8090**, а не весь интернет.

Для изменяющих запросов остались только POST и заголовок `X-IISReports-Request: 1`, который интерфейс добавляет сам. Это не пароль, не авторизация и не проверка доверия к пользователю. CORS не включён. Прежней сверки PublicOrigin и криптографических CSRF-токенов нет, поэтому не требуется настраивать домен в коде.

Для доступа из сети сами настройте нужную привязку, HTTPS и ограничения IIS/VPN/прокси. Отдельного «разрешения домена панели» в программе нет. Не включайте глобальный CORS с произвольными Origin.

## История

Существующая **схема `ir3`, версия 310** совместима. История, сырые строки, активные версии файлов и Enabled сохраняются. Таблицы `AgentState`, `DiscoveryState`, `Jobs` остаются для совместимости, но Simple не зависит от них.

Старые `dbo.IISLogEntries` также не удаляются, однако не объединяются автоматически с `ir3.CurrentRequests`. Не запускайте старый агент и Simple параллельно на одной базе: они используют общую SQL-блокировку импортёра.

Перечитывание с перезаписью, автоматическая смена версии изменённого файла и очистка истории не запускаются. При изменении уже импортированных байтов файл останавливается с объяснением вместо незаметного дублирования или удаления.

## Структура

```text
Setup.ps1                один установщик нового локального сайта
Stop-Legacy.ps1          необязательная остановка старой службы/задачи
web/                     только веб-приложение, Web.config и исходники App_Code
sql/                     совместимая схема ir3; используется установщиком
docs/                    Markdown-инструкции
tests/                   необязательные проверки для разработчика
```

IIS компилирует C# из `App_Code` и `.ashx` при первом обращении. Готового EXE нет, и он не нужен. Исходники всей серверной логики находятся в `web/App_Code` и `web/Reports.ashx`.

## Требования и ограничения

Windows Server с IIS и ASP.NET Framework 4.8; SQL Server с совместимостью базы не ниже 110; читаемые локальные файловые W3C-логи. Для новой установки предпочтителен поддерживаемый SQL Server. Setup добавляет недостающие роли ASP.NET/IIS, если доступны Windows Server cmdlets; Framework и SQL устанавливаются отдельно.

Поддержка автоматического обнаружения ограничена локальными папками `W3SVC*`. Центральные журналы, HTTPERR/FREB, gzip и удалённые UNC-каталоги не добавлены. Имена существующих IIS-сайтов считываются при установке; новый ID позднее отображается как W3SVCn, пока вы не зададите имя.

Количество каталогов/файлов не ограничено искусственной проверкой числа таблиц, но время перечисления и SQL-запросов зависит от объёма. Лимит 12 секунд — мягкий бюджет между порциями, не жёсткий предел HTTP-запроса. Для огромных архивов этот упрощённый вариант не заменяет отдельный сборщик.

## Проверки

Браузерные сценарии выполнены с подставным API, не с вашим IIS. Windows-установка, компиляция C# и SQL-интеграция в среде подготовки не выполнялись. Подробности и способ необязательной проверки компиляции — [TESTING.md](docs/TESTING.md).

Не заявляется, что проект испытан во всех версиях Windows и SQL. При ошибке Setup показывает исходное сообщение; историю удалять для обхода ошибки не нужно.
