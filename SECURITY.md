# Сообщения о безопасности

Описание модели доступа и настройки: [docs/SECURITY.md](docs/SECURITY.md).

Не публикуйте действующие токены, cookie, пароли, Web.config и webhook URL с секретом в открытых issue. Контакт для приватных security reports должен настроить владелец репозитория перед публикацией.

Сбой отрицательного CSRF-теста — блокирующая проблема приёмки, не косметическое предупреждение.
