# Разработка

Для изменений создавайте отдельную ветку, обновляйте CHANGELOG и документацию API/config.

Канонические общие файлы находятся в `web/App_Code`; синхронизируйте их копии в `agent/source`. Серверный код совместим с C# 5 и .NET Framework 4.8. Не добавляйте синтаксис более новой версии без изменения поддерживаемого процесса сборки.

Перед merge: PowerShell parsing, полная Windows-сборка и unit-тесты; для изменений данных — SQL integration на отдельной тестовой базе; для доступа — Test-Http на настоящем IIS. Браузерные mocks не заменяют серверную проверку.

Не коммитьте runtime Web.config, agent-local.config, журналы пользователей, реальные IP/URL с секретами, EXE из неизвестной сборки и GeoIP-базы без лицензии. Лицензия проекта должна быть выбрана владельцем перед публичным распространением.

Схему меняйте отдельными миграциями. Не уничтожайте историю ради упрощения upgrade; документируйте возможность отката.
