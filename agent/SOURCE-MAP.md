# Исходники IISReports.Agent.exe

[← README](../README.md)

EXE **не закрытый бинарник**: весь необходимый C#-код приложен.

| Файл | Назначение |
|---|---|
| `agent/Program.cs` | ServiceBase, цикл сборщика, задания, heartbeat, режимы --console/--once |
| `web/App_Code/V3Core.cs` | Конфигурация, SQL, хеширование, W3C-парсер |
| `web/App_Code/V3Import.cs` | Импорт, поколения, checkpoint, Verify/Replay |
| `web/App_Code/V3Monitoring.cs` | Проверки сайтов, правила, инциденты и webhook |

`agent/IISReports.Agent.csproj` ссылается на общие файлы, не на закрытую DLL. Для сборки через IDE/MSBuild может понадобиться .NET Framework Developer Pack. Основной `Build-And-Test.ps1` использует штатный `csc.exe` установленного Framework и не требует Visual Studio/NuGet.

## Полная сборка

```powershell
.\tools\Build-And-Test.ps1
```

Результат: `build\IISReports.Agent.exe`. В `build\BUILDINFO.json` сохраняются версия, время, компилятор и хеши исходников.

## Автономный комплект

В `agent/source/` находятся идентичные копии четырёх файлов и автономный скрипт:

```powershell
.\Build-Agent-Standalone.ps1
```

Он собирает службу без остальных каталогов проекта. Полная сборка и набор тестов предпочтительнее перед установкой. Автономная сборка не выполняет HTTP/SQL-приёмку.

Редактируйте канонические общие файлы и синхронизируйте копии; проверка поставки обнаруживает расхождение.

## Конфигурация службы

Рядом с установленным EXE должен быть `IISReports.Agent.exe.config`, созданный по `.example` или через `New-InstallConfig.ps1`. Исходники не содержат SQL-паролей. Не копируйте runtime-config в публичный репозиторий.

Служба называется `IISReportsAgentV3`. Это фиксированное имя в текущем коде/установщике; несколько независимых экземпляров на одной машине потребуют отдельной доработки.

`--console` и `--once` используют Windows/SQL-контекст запускающей консоли, а не виртуальную учётную запись службы. Успешный console-run не доказывает права самой службы.
