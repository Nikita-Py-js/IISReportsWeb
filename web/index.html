Какие сайты мониторить

  
Новые локальные сайты IIS обнаруживаются автоматически и включаются по умолчанию.
  Снятие флажка останавливает импорт, но сохраняет историю и контрольные точки. Нажмите «Сохранить выбор».

  

  

    
    
    
    
    
  

  

  




Файлы, контрольные точки и целостность

  
Все новые и ротированные .log-файлы включённых источников импортируются агентом.
  Verify проверяет SHA-256 всех сохранённых блоков. Replay и New version доступны только для включённого доступного источника.
  Пауза не отключает запись журналов в IIS и не меняет правила алертов.

Сборщик v3
Windows-служба IISReportsAgentV3. Открытый браузер для работы не нужен.
Активные HTTP-проверки
GET, без передачи Windows-паролей. Хосты и порты должны быть разрешены в настройках web и agent.
 
Центр инцидентов
open → acknowledged → resolved → closed. Ручное закрытие не означает подтверждённое восстановление.
Задания и уведомления
 
Без webhook в конфиге сборщика сообщения остаются pending. Доставка может повторяться; eventId стабилен.
