# Распространение и сторонние компоненты

Пакет содержит исходники проекта и инструкции. Лицензия на публичное распространение этих исходников в текущем комплекте **не назначена**: владелец проекта должен выбрать её перед публикацией репозитория. Само оформление как GitHub-проект не делает код автоматически MIT/Apache.

.NET Framework, Windows/IIS и SQL Server устанавливаются отдельно по условиям Microsoft. Дистрибутивы Microsoft в архив не включены.

GeoIP/ASN: приложены только примеры формата, не лицензированные реальные базы. Условия используемой базы определяет её поставщик.

Python/Playwright/Chromium используются только для необязательных браузерных тестов и не нужны для работы сайта/службы. Они не включены в ZIP. В проекте нет встроенных шрифтов или внешнего CDN, необходимого для запуска интерфейса.
